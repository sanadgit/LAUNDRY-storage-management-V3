# تقرير اختبار QA

تاريخ الاختبار: 2026-07-13 20:36 +04:00  
النطاق: موقع In & Out Laundry للعميل، الحجز، التتبع، المناطق، الدعم، الإدارة، والسائق.

## ملخص المرحلة

تم تنفيذ اختبار smoke test تقني للتأكد من أن التطبيق يبني بنجاح وأن أهم المسارات العامة لا تفشل على السيرفر المحلي. كما تم إصلاح مسارين تسويقيين مهمين أثناء الاختبار:

- `/portal` أصبح مرادفًا رسميًا لبوابة العميل.
- `/complaints` أصبح مرادفًا رسميًا لصفحة الشكاوى.

## أوامر التحقق

```bash
npm --prefix apps/customer-site run lint
npm --prefix apps/customer-site run build
```

## تدفقات تم تأكيدها من الكود

- الحجز ينشئ طلبًا محليًا ثم ينتقل إلى صفحة التتبع.
- التتبع يدعم البحث برقم الطلب ويدعم `query string`.
- اللغة تتحكم في `html lang` و`dir` بين العربية والإنجليزية.
- صفحات المناطق والخدمات متصلة بالـ SEO meta و JSON-LD.
- بوابة العميل محمية بالتسجيل وتعيد غير المسجل إلى `/auth`.
- الإدارة والسائق لديهما بوابات دخول منفصلة.

## ملاحظات جودة

- يوجد اعتماد حالي على SPA fallback، لذلك فحص HTTP يؤكد تحميل التطبيق وليس محتوى كل صفحة بعد تنفيذ JavaScript.
- الفحص البصري Desktop/Mobile يحتاج تشغيل متصفح فعلي ومراجعة لقطات الشاشة.
- أداة المتصفح الداخلية تعثرت بسبب مشكلة إعداد خارج التطبيق، لذلك لم يتم اعتماد اختبار screenshot في هذه الجولة.

## ما يجب اختباره بصريًا في المرحلة التالية

- الصفحة الرئيسية على Desktop وMobile.
- صفحة الحجز كاملة من اختيار المنطقة إلى إنشاء الطلب.
- صفحة التتبع بعد إنشاء طلب جديد.
- القائمة المتحركة في الموبايل.
- RTL العربي وLTR الإنجليزي بعد تبديل اللغة.
- بوابة العميل على شاشة صغيرة.
- شاشة دخول الإدارة.
- شاشة دخول السائق.
- عدم تداخل النصوص داخل الأزرار والكروت.
- أداء الصور الرئيسية والخدمات.
