# خريطة الموقع

## الصفحات العامة

### الصفحة الرئيسية

المسار:

`/`

الأهداف:

- شرح الخدمة فورًا.
- دفع العميل للحجز.
- دفع العميل للتتبع.
- بناء ثقة.
- عرض الخدمات والفروع.

### صفحة الحجز

المسار:

`/book`

الأهداف:

- إنشاء طلب استلام بأقل خطوات.
- اختيار المنطقة والوقت والخدمة.
- إرسال الطلب للنظام.
- عرض رقم الطلب بعد التأكيد.

### صفحة التتبع

المسار:

`/track`

الأهداف:

- البحث برقم الطلب أو الهاتف.
- عرض حالة الطلب بوضوح.
- تقليل اتصالات العملاء للفرع.
- فتح دعم واتساب إذا احتاج العميل.

### الخدمات
