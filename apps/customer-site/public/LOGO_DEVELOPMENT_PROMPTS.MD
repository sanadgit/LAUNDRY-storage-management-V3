# IN & OUT Laundry Logo Development Prompts

This file is for redesigning and modernizing the main **IN & OUT LAUNDRY** brand logo so it fits the current website style, mascot system, and royal purple identity.

## Current Logo Review

The current logo idea is strong because it clearly communicates **IN / OUT** through the arrows, and the large ampersand gives the brand a memorable visual identity.

However, for the current website direction, it needs refinement:

- The black visual weight is too heavy for the clean premium website style.
- The vertical composition is difficult to use in the navbar and mobile header.
- The Arabic and English text at the bottom is small and compressed.
- The arrow shapes feel too sharp compared with the soft, glossy, premium design language.
- The logo needs a cleaner icon-only version for favicon, app icon, Outty badge, loading screens, and small UI use.

## Recommended Logo System

Create three versions:

1. **Primary Horizontal Logo**
   - Icon on the left.
   - `IN & OUT LAUNDRY` on the right.
   - Small Arabic line: `مصبغة إن آند آوت`.
   - Best for website header, footer, invoices, and official documents.

2. **Compact Icon Mark**
   - Simplified ampersand + IN / OUT arrows.
   - No long text.
   - Best for favicon, app icon, social avatar, watermark, and Outty badge.

3. **Premium Emblem Version**
   - More polished brand-mark version for hero sections, packaging, stickers, delivery bags, and uniforms.
   - Can use subtle satin/glass highlights while staying readable.

## Brand Colors

Use:

```text
Royal purple: #8F00FF
Deep royal plum: #21002F
Luminous satin violet: #C026D3
Pure white: #FFFFFF
Light silver: #E5E7EB
Very pale lavender: #FBF7FF
```

Avoid:

```text
Blue, teal, green, orange, beige, brown, heavy black dominance, messy gradients, low contrast, overly childish cartoon shapes.
```

## Practical Notes

- Ask the tool for SVG/vector output if available.
- If Arabic text is distorted, generate the icon and English version only, then add Arabic text manually in design software.
- Keep one icon mark consistent across navbar, favicon, Outty badge, packaging, and delivery graphics.
- The logo should still be recognizable in one color.
