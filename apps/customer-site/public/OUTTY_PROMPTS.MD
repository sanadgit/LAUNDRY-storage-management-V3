# Outty Mascot Image Prompts

Use this file to generate the Outty mascot images for **IN & OUT LAUNDRY**.

## Brand Logo Reference

Use the current store logo as the main visual reference:

![IN & OUT Laundry logo](./favicon.svg)

When using Midjourney, Leonardo, Ideogram, Firefly, DALL-E, or similar tools:

1. Upload `apps/customer-site/public/favicon.svg` as a reference image.
2. Use the prompt for the required filename.
3. Keep the same character design, color palette, camera angle, and lighting across all images.
4. Export as PNG with transparent background whenever possible.

## Master Style Prompt

Use this style block with every prompt:

```text
Create a premium 3D mascot character named Outty for a laundry brand called IN & OUT LAUNDRY. Outty is a friendly, polished, modern laundry mascot inspired by the brand logo: rounded wave shape, clean circular movement, fresh laundry energy, and a premium service feeling. Use the uploaded IN & OUT Laundry logo as exact brand reference. Add the logo mark as a small badge on Outty's chest, apron, cap, laundry bag, or accessory when it fits naturally. Do not invent or distort the logo text. If text cannot be copied perfectly, use only the logo symbol/badge.

Character style: glossy royal purple satin body, pure white face or front panel, soft silver accents, clean white gloves, rounded friendly proportions, confident helpful expression, high-end 3D app mascot quality, Pixar-like polish but more premium and less childish, realistic soft studio lighting, subtle reflections, glassmorphism highlights, crisp silhouette, generous padding.

Brand colors: royal purple #8F00FF, deep royal plum #21002F, luminous satin violet #C026D3, pure white, light silver, very pale lavender highlights. Avoid blue, teal, green, orange, beige, brown, messy colors, cheap cartoon style, flat clipart, dark backgrounds, harsh shadows, blurry details.

Output: centered full character or icon composition, transparent background, PNG, 2048x2048, clean edges, readable at small website size, no watermark, no random text, no extra logo variants.
```

## Negative Prompt

```text
No blue color palette, no teal, no green, no orange, no beige, no brown, no messy background, no random letters, no misspelled text, no fake brand name, no watermark, no extra characters, no human person, no scary face, no childish baby style, no low-resolution render, no flat emoji, no distorted hands, no clutter, no dark background, no heavy outline.
```

## Consistency Notes

- Keep Outty's face, body shape, proportions, and badge placement consistent across all generated images.
- Preferred output size: `2048x2048`.
- Preferred background: transparent PNG.
- Website display target: mascot cutout, not full poster.
- If the tool struggles with the logo text, use the uploaded logo symbol only and avoid generating letters.
