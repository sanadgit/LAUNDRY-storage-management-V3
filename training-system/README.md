# In & Out Laundry - Training System Index

This folder contains the complete operational training ecosystem for In & Out Laundry.

## Deliverables

| File | Purpose |
| --- | --- |
| 01-full-training-manual.md | Complete 19-module training manual with SOP, safety, quality, quiz, KPI, and visual guidance |
| 02-course-outline.md | Course structure, audience, timing, assessment, and certification levels |
| 03-presentation-slides-content.md | Slide-by-slide content, visual design system, icons, and module design matrix |
| 04-employee-quick-guide.md | Simple daily guide for workers and frontline staff |
| 05-supervisor-handbook.md | Shift management, staff monitoring, quality inspection, and KPI control |
| 06-sop-library.md | Fast SOP library for operational reference |
| 07-daily-checklist-pack.md | Opening, closing, machine, delivery, packaging, and supervisor audit checklists |
| 08-incident-templates-pack.md | Damage, missing item, complaint, machine issue, and handover templates |
| 09-kpi-tracking-guide.md | KPI definitions, dashboards, department targets, and action rules |

## Recommended Use

1. Train new staff using the course outline and full manual.
2. Use the slide content to create PowerPoint or Canva training decks.
3. Print the employee quick guide and SOP library for branch reference.
4. Supervisors should use the checklist pack and handbook every shift.
5. Managers should review the KPI guide weekly and monthly.

## Design Style

Use a clean UAE corporate look:
- Deep navy for authority.
- Teal for cleanliness and technology.
- Gold for premium service.
- Red only for safety, incidents, and emergency warnings.
- Real branch photos are preferred over generic stock images.
