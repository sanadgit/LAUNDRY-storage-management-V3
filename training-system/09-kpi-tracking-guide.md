# In & Out Laundry - KPI Tracking Guide

## KPI Principles

KPIs must improve the branch, not create fear. Track speed, quality, safety, customer satisfaction, and cost together. A fast branch with many mistakes is not successful.

## Core KPI Dashboard

| KPI | Definition | Suggested Review |
| --- | --- | --- |
| Orders received | Number of new customer orders | Daily |
| Pieces processed | Total items completed by department | Daily |
| Pieces per labor hour | Completed pieces divided by labor hours | Daily/weekly |
| Rewash rate | Rewash items divided by completed items | Daily/weekly |
| Pressing defects | Repress or rejected finish items | Daily |
| Packaging error rate | Wrong label, incomplete order, damaged packaging | Daily |
| Scan compliance | Required scans completed divided by expected scans | Daily |
| Lost item count | Items not found after normal search | Immediate/monthly |
| Damage claim rate | Damage claims divided by total orders | Monthly |
| On-time delivery | Deliveries completed within promised time | Daily |
| Failed delivery rate | Failed deliveries divided by attempted deliveries | Daily |
| Complaint rate | Complaints divided by total orders | Weekly/monthly |
| Customer satisfaction | Rating or feedback score | Weekly/monthly |
| Machine downtime | Time machine unavailable | Daily/weekly |
| Chemical cost per kg | Chemical cost divided by processed kg | Weekly/monthly |
| Safety incidents | Accidents and near misses | Immediate/monthly |

## Root Cause Categories

Use these categories when recording errors:
- Reception error.
- Barcode or scan error.
- Sorting error.
- Washing error.
- Drying error.
- Pressing error.
- Packaging error.
- Storage error.
- Delivery error.
- Customer instruction issue.
- Machine issue.
- Staff training issue.

## Supervisor Action Rules

| KPI Problem | First Action |
| --- | --- |
| High rewash | Audit sorting, stains, wash cycle, detergent dosing |
| Low pressing output | Check staffing, heat setup, garment mix, skill level |
| High packaging errors | Add final count and label verification |
| Low scan compliance | Retrain staff and audit scan points |
| Late delivery | Check ready time, loading time, route plan, driver update |
| High complaints | Group by complaint type and fix root cause |
| Machine downtime | Create maintenance log and backup plan |

## Monthly Management Review

Review:
- Best branch performance.
- Weakest KPI by branch.
- Top 5 complaint causes.
- Top 5 rewash causes.
- Lost and damaged item trend.
- Staff training gaps.
- Machine maintenance needs.
- Automation improvement opportunities.

## KPI Training Message for Staff

Simple message:
"KPIs help us see where work is smooth and where we need help. We use KPIs to improve training, tools, teamwork, and customer service."
